# Where’s My Pet?

Game prototipe Three.js, berbahasa Indonesia. Buka melalui server HTTP statis dari `dist/`.

- 50 level prosedural dalam enam tema, 50 profil hewan.
- Kota miniatur, lalu lintas dan warga bergerak, pepohonan bergoyang, sungai beranimasi.
- Raycasting objek, kamera orbit/zoom, keyboard dan tombol sentuh.
- Petunjuk brosur, warga dan PetNet simulasi di dalam game.
- Batas waktu, pengambilan hewan, pengembalian ke pemilik, reward acak.
- Misi truk setelah waktu habis, peralatan gratis atau alat toko, kondisi kalah dan ulang.
- Delapan peralatan dengan efek aktif; progres disimpan lewat localStorage.
- Musik serta efek kota disintesis dengan Web Audio, diaktifkan pengguna.

Batas prototipe: model hewan bergaya sederhana, PetNet bukan pencarian internet langsung, suara warga berupa efek sintesis; lingkungan berbagi kerangka tata kota dengan variasi tema prosedural. Tidak ada backend atau penyimpanan lintas perangkat.

Three.js r170 dilisensikan MIT; lisensi dicantumkan di file vendor.
